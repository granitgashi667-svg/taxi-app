# 🚕 TaxiApp 2.0 — TaxiDispatch Pro

Sistem profesional taxi me shumë platforma për kompani taxi në Kosovë.

---

## 📋 Çka përmban

- **6 faqe** — Zyra, Shoferi, Klienti, Menagjeri, Drejtori, TV Display
- **Live tracking** — Pozicionet e veturave në kohë reale
- **SMS automatike** — Njoftime për klientët
- **Geofencing** — 20m afër klientit → SMS + dritë pembe
- **Statistika të plota** — Për çdo operator, shofer, klient
- **Taksimetri Bluetooth** — Lidhje direkte me taksimetrin
- **Call Center** — Pickup, Hangup, Hold, Transfer (F1-F4)
- **TV Display** — Ekran i madh për zyrë
- **PWA** — Instalim si app në telefon / PC
- **Chat live** — Mesazhe klient ↔ shofer
- **SOS emergjencë** — Për shoferin dhe klientin
- **2FA** — Verifikim me dy hapa
- **Audit Log** — Gjurmim i plotë i veprimeve
